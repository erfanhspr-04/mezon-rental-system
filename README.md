# سامانه کرایه لباس کودک — مزون کودکانه

سامانه مدیریت رزرو و کرایه لباس کودک (دخترانه، پسرانه، نوزاد، ست مادر و کودک)
با تقویم شمسی، تشخیص تداخل رزرو، چاپ رسید و خروجی اکسل.

## ساختار پروژه

```
mezon-project/
├── index.html          ← نقطه ورود (ساختار صفحه و ناوبری)
├── css/
│   └── style.css       ← تمام استایل‌ها و طراحی رابط کاربری
└── js/
    └── app.js          ← تمام منطق برنامه (بخش‌بندی‌شده بر اساس SOLID)
```

## اجرای پروژه

**روش ۱ — ساده‌ترین:** کافی است `index.html` را در مرورگر باز کنید (همه‌چیز آفلاین کار می‌کند).

**روش ۲ — با VS Code:** پوشه را در VS Code باز کنید و با افزونه **Live Server** اجرا کنید.

## بخش‌های فایل app.js (معماری SOLID)

| بخش | مسئولیت |
|---|---|
| `StorageService` | ذخیره‌سازی در localStorage |
| `JalaliDateService` | تبدیل و قالب‌بندی تاریخ شمسی |
| `ReservationRepository` / `ClothingRepository` | دسترسی به داده‌ها |
| `ReservationService` | محاسبه مبالغ، تشخیص تداخل، جستجو و آمار |
| `ClothingService` | مدیریت موجودی لباس‌ها |
| `DashboardView` / `ReservationsView` / `CalendarView` / `InventoryView` | نمایش و رویدادهای UI |
| `App` | ریشه ترکیب و تزریق وابستگی‌ها |

## امکانات

- ثبت/ویرایش/حذف رزرو با محاسبه خودکار مبلغ کل و مانده
- هشدار تداخل: یک کد لباس در یک روز برای دو مشتری
- جستجو بر اساس نام، موبایل، کد لباس و بازه تاریخ
- تقویم شمسی ماهانه با جزئیات هر روز
- مدیریت موجودی لباس‌ها و تاریخچه رزرو هر لباس
- چاپ رسید، خروجی اکسل (CSV)، پشتیبان‌گیری و بازیابی (JSON)
- ذخیره‌سازی روی همان دستگاه (localStorage)

## تغییر نام مزون

در فایل `js/app.js` ثابت `BOUTIQUE_NAME` را تغییر دهید.
